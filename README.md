## Local Development 

To run this project locally, ensure you have Node.js and npm installed:

```sh
git clone [https://github.com/chunyaliu1115/uban_map_portfolio.git](https://github.com/chunyaliu1115/uban_map_portfolio.git)
cd uban_map_portfolio
npm install
npm run dev
